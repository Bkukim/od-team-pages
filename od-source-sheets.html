내부데이터 작업 시트

시트 열기
  • test납품 작업 전에 신입 작업자가 연습하는 작업 목록입니다. 테스트 작업을 확인하고 진행 상황을 입력합니다.탭 열기 →
  • work_sheet내부 데이터의 큐보이드 작업 시트입니다. 해야 할 작업과 진행 상태(작업 중, 완료)를 표시합니다.탭 열기 →
  • code_error내부 데이터 작업물을 코드로 검사해 에러가 나온 건의 목록입니다. 고쳐야 하는 에러인지 허용되는 에러인지 확인해 반려(retake) 또는 pass로 표시합니다.탭 열기 →
  • ratio_subclass내부 데이터 작업물 중 큐보이드 크기가 비정상적인 건의 목록입니다. 잘못 작업한 건지 허용되는 크기인지 확인해 반려(retake) 또는 pass로 표시합니다.탭 열기 →
  • img_inspect내부 데이터 작업 이미지를 직접 보고 놓친 작업이나 잘못 지정한 클래스가 있는지 확인합니다. 결과에 따라 반려(retake) 또는 pass로 표시합니다.탭 열기 →
  • work_logimg 작업을 한 시간에 몇 프레임 했는지 직접 기록하는 탭입니다. 날짜별로 이름과 시간대별 프레임 수를 적습니다.탭 열기 →
